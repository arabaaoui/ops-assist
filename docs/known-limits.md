# Known limits

This index consolidates the limitations documented in the project READMEs and workshops. The linked workshops retain their detailed examples and prerequisites; neither the examples nor the tests establish production readiness.

## Models, data and conclusions

All bundled incidents and documents are fictional. Replay is not live infrastructure. Model responses can be wrong or nondeterministic; a cited observation, a high confidence, a matching identifier or a fresh document does not prove causation. Tool output, logs, retrieval and feedback are untrusted. The scripted demo and tests never evaluate a real model. Profiles, availability, residency, cost, context sizes and fallback behavior depend on provider configuration. Fallback covers selected HTTP errors before output, not all failures. Token counts and hardware sizing are estimates; GPU and local runtime discovery are incomplete. See workshops [01](../ateliers/01-premier-appel/README.md), [02](../ateliers/02-sortie-structuree/README.md), [03](../ateliers/03-premier-agent/README.md), [04](../ateliers/04-sous-systemes/README.md), [05](../ateliers/05-decision-architecture/README.md), [06](../ateliers/06-memoire/README.md), [07](../ateliers/07-budget-contexte/README.md), [22](../ateliers/22-transformers/README.md), [27](../ateliers/27-materiel/README.md), [28](../ateliers/28-cuda/README.md), [29](../ateliers/29-inference/README.md), [30](../ateliers/30-clouds/README.md) and [31](../ateliers/31-couts/README.md).

## Sources, memory and retrieval

Live fixtures are hand-made, not server captures; Loki filtering needs an indexed level label and changes require a configured file. Timeouts abandon bounded worker threads. Sessions and remote tasks default to memory; persistent sessions and saved reports can contain unredacted data. Redaction is heuristic. MCP cannot carry injected Python sources; A2A requires a trusted TLS proxy for remote use and its card is public. The graph and retrieval use bounded data, lexical heuristics and freshness thresholds; none proves relevance or correctness. Drafts need human review before approval. See [08](../ateliers/08-appel-d-outils/README.md), [09](../ateliers/09-mcp/README.md), [10](../ateliers/10-skills/README.md), [11](../ateliers/11-a2a/README.md), [12](../ateliers/12-roles/README.md), [14](../ateliers/14-passerelle/README.md), [15](../ateliers/15-embeddings/README.md), [16](../ateliers/16-rag/README.md), [17](../ateliers/17-variantes-rag/README.md), [18](../ateliers/18-graphrag/README.md), [19](../ateliers/19-rag-agentique/README.md) and [20](../ateliers/20-base-vivante/README.md).

## Security, evaluation and operations

Writes are disabled by default; confirmed replay modifies simulated state, live rollback is refused and demo rollback needs an injected client. Audit, traces and redaction require protected storage and retention; tracing exports metadata to a configured collector and separately installed instrumentation is outside its guarantee. Limits and budgets are per invocation or informational as documented, not a distributed policy. The public evaluation data and lexical scorer do not prove accuracy, resist paraphrases reliably or cover unseen incidents; the LoRA split reuses source alerts and demonstrates reformulation rather than generalization. Cost scenarios are estimates, not bills; cache behavior depends on the provider. Red-team probes cover selected cases, not all attacks. The behavior fingerprint omits external model revisions, retrieval settings and mutable knowledge. CI and these deployment examples do not establish branch protection, operational ownership, monitoring, emergency stop or recovery. See [13](../ateliers/13-securite/README.md), [21](../ateliers/21-donnees/README.md), [23](../ateliers/23-changer-un-modele/README.md), [24](../ateliers/24-lora/README.md), [25](../ateliers/25-distillation/README.md), [26](../ateliers/26-renforcement/README.md), [32](../ateliers/32-aidlc/README.md), [33](../ateliers/33-evaluations/README.md), [34](../ateliers/34-traces/README.md), [35](../ateliers/35-red-team/README.md), [36](../ateliers/36-ci-cd/README.md), [37](../ateliers/37-echecs/README.md), [38](../ateliers/38-plateforme/README.md), [39](../ateliers/39-echelle/README.md) and [40](../ateliers/40-production/README.md).

The examples in [deploy](../deploy/) use placeholder images and secret references. Kubernetes denies all egress until explicitly adapted, which prevents DNS and model access; its `emptyDir` state is ephemeral. Cloud Run requires a writable state location and separately configured provider access. The application advertises a loopback address in its A2A card, so external clients need a trusted proxy rewriting it. Neither manifest provisions secrets, TLS, an image, access policy or operational monitoring; no deployment has been verified.
