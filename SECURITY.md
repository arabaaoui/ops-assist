# Security

This educational project uses fictional data and is read-only by default. Tool outputs are untrusted; write access requires explicit enablement and confirmation, and live rollback is refused. Security checks are not a guarantee of safety. See [known limits](docs/known-limits.md) and the [production review](docs/production-review.md).

Please report a suspected vulnerability privately to the repository maintainers through the hosting platform's private vulnerability reporting feature, if available. Do not post credentials, sensitive incident data or exploitation details in a public issue. There is no promised response time or maintained-version policy; verify the project's current maintenance status before relying on it.
